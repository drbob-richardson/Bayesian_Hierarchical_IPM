# Finite-Population Profile-Transition Model

## Motivation

The independent Poisson and Gamma-Poisson profile likelihoods correctly use
the IPM to describe the expected next size profile, but they do not reproduce
the dependence generated by a finite collection of individuals. In
particular, a surviving individual can enter only one destination size bin,
which induces negative covariance among survivor counts. Unobserved
reproductive heterogeneity can induce positive covariance among recruit-size
bins.

The new finite-population model retains the Poisson-process IPM mean while
replacing the independent-bin likelihood with a multivariate synthetic
likelihood based on the finite-population transition moments.

## Transition Moments

Let \(N_{tj}\) be the number of individuals in source size bin \(j\). Define

\[
Q_{ij} = \Delta P_{ij}, \qquad
F_{ij} = \Delta R_{ij}, \qquad
K_{ij} = Q_{ij} + F_{ij},
\]

where \(P\) and \(R\) are the survival-growth and fertility components of the
IPM kernel. Conditional on the source profile, the next-profile mean is

\[
\boldsymbol{\mu}_{t+1} = K\mathbf{N}_t.
\]

For homogeneous individuals within source bins, the demographic covariance is

\[
\Sigma_{\mathrm{dem}}
=
\operatorname{diag}(K\mathbf{N}_t)
-
Q\operatorname{diag}(\mathbf{N}_t)Q^\mathsf{T}.
\]

The subtraction is the finite-population survivor dependence: the same fish
cannot survive into multiple size bins. To marginalize unobserved reproductive
heterogeneity, the implementation additionally uses

\[
c_F^2 F\operatorname{diag}(\mathbf{N}_t)F^\mathsf{T},
\]

where \(c_F^2=1\) corresponds to an unobserved 1:1 mixture of non-reproductive
males and females producing at twice the population-average fecundity.

When profile detection \(p<1\), the source population is estimated by
\(\widehat{\mathbf{N}}_t=\mathbf{Y}_t/p\). Approximate source-profile sampling
uncertainty and destination-profile binomial sampling uncertainty are
propagated through the transition covariance.

## Likelihoods

Two versions are implemented:

- `one_step_finite_population`: finite-population transition moments alone.
- `one_step_finite_population_overdispersed`: the same covariance plus
  independent residual variance \(\mu_i^2/\phi\), where \(\phi\) is estimated.

The observed next profile is evaluated with a multivariate normal synthetic
likelihood. A count-scale continuity variance floor prevents empty tail bins
from creating an artificial likelihood singularity.

The overdispersed version is the more robust default because the moment model
does not fully represent within-bin size variation, temporal environmental
effects, or every source of individual heterogeneity.

## Exact State-Space Alternative

An exact finite-population formulation would introduce latent true abundance
by size bin. Survivor transitions would follow source-bin multinomials,
recruitment would follow a compound Poisson process, and observed profiles
would follow binomial detection models. That model is scientifically
attractive, but fitting it requires particle MCMC, sequential Monte Carlo, or
specialized discrete-state marginalization. The synthetic likelihood is a
computationally tractable intermediate model that retains the essential
cross-bin dependence.

## Reproduction

The pilot comparison can be reproduced with:

```sh
PROFILE_ALT_EXPERIMENT=finite_population_pilot_v2 \
PROFILE_ALT_REPLICATES=10 \
PROFILE_ALT_DRAWS=500 \
PROFILE_ALT_SCENARIOS=parent_excitation_sparse,parent_excitation_dense \
PROFILE_ALT_METHODS=one_step_gamma_poisson,one_step_finite_population,one_step_finite_population_overdispersed \
Rscript scripts/run_profile_process_alternatives.R
```

The publication-scale comparison uses:

```sh
PROFILE_ALT_EXPERIMENT=finite_population_confirmatory \
PROFILE_ALT_REPLICATES=100 \
PROFILE_ALT_DRAWS=500 \
PROFILE_ALT_SCENARIOS=parent_excitation_sparse,parent_excitation_dense \
PROFILE_ALT_METHODS=one_step_gamma_poisson,one_step_finite_population_overdispersed \
Rscript scripts/run_profile_process_alternatives.R
```

## Confirmatory Results

The confirmatory comparison used 100 simulated datasets under each
parent-excitation design and compared the independent Gamma-Poisson likelihood
with the overdispersed finite-population likelihood. All 400 fits completed;
399 had positive-definite Laplace information matrices.

| Design | Quantity | Gamma-Poisson coverage | Finite-population coverage | Gamma-Poisson RMSE | Finite-population RMSE |
|---|---|---:|---:|---:|---:|
| Dense | Recruitment parameter group | 0.650 | 0.920 | 0.0455 | 0.0371 |
| Sparse | Recruitment parameter group | 0.845 | 0.934 | 0.0663 | 0.0589 |
| Dense | Recruitment at 80 mm | 0.680 | 0.920 | 0.0108 | 0.0089 |
| Sparse | Recruitment at 80 mm | 0.890 | 0.970 | 0.0157 | 0.0137 |
| Dense | Population growth rate | 1.000 | 0.950 | 0.0066 | 0.0060 |
| Sparse | Population growth rate | 0.960 | 0.970 | 0.0220 | 0.0244 |

The finite-population model substantially improved recruitment calibration and
usually reduced recruitment RMSE. It did not uniformly improve every vital
rate. Under dense complete profiles, growth-group coverage changed from 0.757
to 0.707 and survival-group coverage changed from 1.000 to 0.935. The
Gamma-Poisson likelihood was conservative for dense-profile survival, whereas
the finite-population synthetic likelihood was slightly overconfident.

These results support using the finite-population covariance as part of the
main model, while retaining residual overdispersion and investigating either a
global covariance inflation parameter or a sandwich/Godambe posterior
adjustment for robust uncertainty calibration.
