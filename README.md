# profileIPM

Research code for studying when repeated cross-sectional size profiles can
identify the vital rates of a size-structured population.

The central experiment separates:

1. an individual-based biological data generator;
2. observation processes producing size profiles and mark-recapture data; and
3. recovery models fitted without access to individual identities.

This prevents the inverse integral projection model (IPM) from being validated
only on data generated by the same IPM used for estimation.

## Core Questions

- Which vital rates are identifiable from size profiles alone?
- Which combinations of survival, growth, and realized recruitment are
  confounded?
- How do time-series length, sample size, demographic variation, detection, and
  prior strength affect recovery?
- Can population growth, future size profiles, or other demographic
  functionals be estimated when the individual vital rates cannot?
- How much auxiliary individual-level data are needed to resolve confounding?

## Repository Layout

- `R/`: simulation, observation, and numerical IPM functions
- `scripts/`: executable analyses
- `tests/`: lightweight checks for the simulation scaffold
- `configs/`: simulation scenario definitions
- `docs/`: research roadmap and model specification
- `paper/`: manuscript materials as the project develops

## Quick Start

From the repository root:

```r
source("scripts/run_smoke_simulation.R")
source("scripts/run_identifiability_demo.R")
source("tests/test_simulator.R")
```

The full Bayesian multi-year identifiability experiment is:

```r
source("scripts/run_bayesian_identifiability.R")
source("scripts/summarize_bayesian_identifiability.R")
source("scripts/run_bayesian_process_identifiability.R")
```

Current proof-of-concept and diagnostic figures can be regenerated with:

```r
source("scripts/make_current_diagnostic_plots.R")
```

The broad, resumable Monte Carlo grid is run and summarized with:

```r
source("scripts/run_monte_carlo_grid.R")
source("scripts/summarize_monte_carlo_grid.R")
source("scripts/audit_monte_carlo_mcmc.R")
source("scripts/plot_monte_carlo_grid.R")
```

Results from the first broad grid are documented in
[`docs/monte-carlo-first-grid.md`](docs/monte-carlo-first-grid.md).

The first external vital-rate information and prior-strength experiments are
documented in
[`docs/prior-information-first-run.md`](docs/prior-information-first-run.md).

The targeted and confirmatory auxiliary-fecundity experiments are documented
in
[`docs/auxiliary-fecundity-confirmatory.md`](docs/auxiliary-fecundity-confirmatory.md).

The continuous transport-bias experiment across multiple biological truths is
documented in
[`docs/transportability-boundary-first-run.md`](docs/transportability-boundary-first-run.md).

```r

source("scripts/summarize_paired_data_benchmark.R")

```

The finite-population profile-transition likelihood, including cross-bin

settled.

## Immediate Milestones

1. Lock the biological simulator and observation models.
2. Implement a positive numerical-quadrature inverse IPM.
3. Validate recovery under correctly specified and misspecified models.
4. Map likelihood-informed and prior-informed parameter directions.
5. Compare profile-only, mark-recapture, and integrated analyses.

See [`docs/research-roadmap.md`](docs/research-roadmap.md) for the full design.
